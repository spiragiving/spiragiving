# Spira Giving Colorado

**Giving culture room to grow.**

Live website: [spiragiving.dev](https://spiragiving.dev)

This branch is the static GitHub Pages publication for the nonprofit redesign. The original Next.js source and generated export are maintained on [main](https://github.com/spiragiving/spiragiving/tree/main/web).

Read [the research and development plan](NONPROFIT-PLAN.md) for public records, sources and content decisions. The website includes the foundation story, giving record, transparency and filings, sourced journal, giving inquiries, volunteer interest and contact.

Forms prepare email drafts and downloadable copies. They do not send messages or process payments. The foundation only contributes to preselected charitable organizations and does not accept unsolicited funding requests.

The original nonprofit .html URLs and previous SaaS routes lead to the redesigned pages. CNAME preserves the existing custom domain, and .nojekyll allows the Next.js static assets to be served.
