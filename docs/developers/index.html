Usage and errors

Design clear request limits, bounded retries, and observable event history.

Error handling and operational patterns

Validate inputs before creating an action. Treat repeated events as possible duplicates. Retry transient errors with bounded exponential backoff; surface persistent errors for review. Redact secrets and unnecessary personal data from logs.
